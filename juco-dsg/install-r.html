Install R and RStudio

JUCo Data Science & Modelling Research Group · Step-by-step installation guide

What are they? R is the language that does the calculations. RStudio is the program you work in: it makes R easier to use. You need both, and both are free.
The one rule: install R first, then RStudio.

Choose your computer

Windows

  1. Download R. Open cran.r-project.org/bin/windows/base and click the big link Download R for Windows at the top.
  2. Install R. Open the downloaded file (it ends in .exe). Click Yes, then Next on every screen. Keep all the default settings. Click Finish.
  3. Download RStudio. Open posit.co/download/rstudio-desktop and click Download RStudio Desktop for Windows.
  4. Install RStudio. Open the downloaded file. Click Next, Next, Install, Finish.
  5. Open RStudio. Click the Start menu, type RStudio, and open it. (Open RStudio, not “R”.)
Windows 10 or older? The newest RStudio is made for Windows 11. Try the steps above first. If RStudio will not install or open, use the No install tab, or ask a facilitator for an older RStudio version.

Mac

  1. Check your chip. Click the Apple menu (top left) and choose About This Mac. Look for Chip: Apple M1/M2/M3… (Apple silicon) or Processor: Intel.
  2. Download R. Open cran.r-project.org/bin/macosx. Choose the file for your chip: arm64 for Apple silicon, x86_64 for Intel. The file ends in .pkg.
  3. Install R. Open the .pkg file. Click Continue and Install, and type your Mac password when asked. If the Mac blocks the file, hold Control, click the file, choose Open, and confirm.
  4. Download RStudio. Open posit.co/download/rstudio-desktop and download the Mac file (it ends in .dmg).
  5. Install RStudio. Open the .dmg file and drag the RStudio icon into the Applications folder.
  6. Open RStudio from Applications or Launchpad. If the Mac asks “Are you sure?”, click Open.
Older Mac? The newest RStudio needs macOS 15 or later. If your Mac is older and RStudio will not open, use the No install tab, or ask a facilitator for an older RStudio version.

Linux (Ubuntu)

  1. Open the Terminal (press Ctrl + Alt + T).
  2. Install R. Type these two lines, pressing Enter after each. Type your password when asked. 
    sudo apt update
sudo apt install r-base
    This gives the R version that comes with your Ubuntu. For the newest R, follow the official page: cran.r-project.org/bin/linux/ubuntu.
  3. Download RStudio. Open posit.co/download/rstudio-desktop and download the .deb file for Ubuntu.
  4. Install RStudio. In the Terminal, go to your Downloads folder and install the file: 
    cd ~/Downloads
sudo apt install ./rstudio-*.deb
  5. Open RStudio from the applications menu.
The newest RStudio is made for Ubuntu 22, 24 and 26 and Debian 13. Fedora and Red Hat use an .rpm file from the same page. Other Linux systems: see cran.r-project.org/bin/linux.

No install: use R in your browser

Good for: a Chromebook, a tablet, an old computer, or a computer where you cannot install programs.

  1. Open posit.cloud in your browser.
  2. Click Sign Up and choose the free plan. You can sign in with a Google account.
  3. Click New Project, then New RStudio Project.
  4. Wait a moment. RStudio opens inside the browser. It looks the same as on a computer.
The free plan has monthly limits on hours of use, and it needs internet all the time. A phone screen is too small for real work. Use this as a backup, and install on a computer when you can.

Check that it works

  1. Open RStudio. Find the Console (bottom left, with the > sign).
  2. Type this and press Enter:
    1 + 1
    You should see [1] 2.
  3. Type this and press Enter, to see your R version:
    R.version.string
  4. Test that you can add packages (needs internet, takes a few minutes):
    install.packages("ggplot2")
library(ggplot2)
    No red “Error” means it worked.
Done! Take a screenshot of your Console showing [1] 2 and your R version, and send it to the group before Module 5.

If something goes wrong

ProblemTry this
RStudio says it cannot find RR is not installed yet. Install R, then close and open RStudio again.
The download is very slow or stopsUse campus Wi-Fi, or ask a facilitator for the files on a USB stick.
“You need permission” or a password is askedUse the computer’s owner (administrator) password. On a lab computer, ask the lab technician.
Mac says the file “cannot be opened”Hold Control, click the file, choose Open, then Open again.
RStudio will not install on an older Windows or MacUse the No install option, or ask a facilitator for an older RStudio version.
install.packages shows a warning in redA warning is often fine. Read it for the word “Error”. If you see “Error”, copy the message and send it to the group.
Still stuckSend a screenshot and your system (Windows, Mac or Linux) to the facilitators.
