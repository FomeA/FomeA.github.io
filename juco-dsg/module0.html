Module 0 · Before We Touch Code

Understanding data, structure, and tools before programming begins.

🎯 What you will learn

  • What data is (beyond just numbers)
  • How datasets are structured (rows & columns)
  • What software like R actually does
  • How to think like a data user

📊 What is data?

Data is recorded information such as numbers, text, dates, or observations collected from the real world.

📁 How data is organized

  • Rows = observations (people, events, samples)
  • Columns = variables (age, height, score, etc.)

💡 Why this matters

If you understand structure first, coding becomes easier because you are working with ideas — not memorizing commands.

🧭 Before you continue

  • No programming experience needed
  • Basic computer use is enough
  • Curiosity matters most
